## 二、前期准备（3步搞定素材）
### 1. 下载袁阔成纯净音频
去B站搜：**袁阔成 三国演义 无背景音乐 原版**
用任意B站音频下载工具，只下**纯人声、没配乐、没音效**的片段。
凑够 **20～30分钟** 即可。

### 2. 用Audacity处理音频
1. 安装Audacity（免费官网直接下）
2. 导入音频 → 效果→降噪（先选一段空白噪音采样，再整段降噪）
3. 手动切割成 **3～8秒 一小段**
4. 删掉：口水音、大换气、模糊音质、有配乐的片段
5. 统一导出：**WAV 44100Hz 单声道 16bit**
6. 新建文件夹：`yuan_raw`，把所有切好的wav放进去

## 三、打开RVC开始训练（逐一点鼠标教程）
1. 解压刚才的整合包，双击 **run_web.bat** 自动打开网页界面
2. 顶部切换到 **训练 选项卡**
3. 填写参数（直接照抄，一字不改）
- 模型名字：`yuan_kuocheng`
- 采样率：**40k**
- 训练方式：**全新训练**
- BatchSize：**8**
- 学习率：**0.0002**
- 总训练轮数：**400**
- 保存间隔：**50轮**

4. 选择数据集路径：选中你刚才建好的 `yuan_raw` 文件夹
5. 点击 **开始预处理数据集** 等待自动处理完成
6. 预处理完，点 **开始训练**
- 有N卡自动全速跑
- 4G显存大概40～60分钟跑完
- 每50轮自动保存模型，不用管
